# Estado de los sistemas de NOCTURNA

## Base de codigo creada
- Configuracion general y configuraciones de monstruos, objetos y objetivos.
- Movimiento, camara, linterna e interfaz iniciales.
- Eventos de red y servicios iniciales de inventario, objetivos e interacciones.
- Salud, guardado de progreso y deteccion inicial de sonidos.
- Cerebro inicial de persecucion y registro de monstruos.
- Administracion y controles moviles iniciales.

## Pendiente de desarrollo y pruebas
- Comportamiento exclusivo y completo de cada monstruo.
- Imitacion realista de voces, movimiento por paredes y sistema de observacion.
- Cambios ambientales del Coloso.
- Mapas, modelos, animaciones, sonidos, cinemáticas y contenido narrativo finales.
- Cooperativo, sincronizacion e interfaz visual del inventario.
- Pruebas de seguridad de las acciones remotas, rendimiento y compatibilidad.
- Pruebas dentro de Roblox Studio.

Este documento describe el estado del codigo, no certifica que el juego este terminado o probado.
