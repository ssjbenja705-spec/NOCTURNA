# NOCTURNA - Sistema de mapa

El generador crea una instalación subterránea de 25 sectores.

Incluye:
- Laberinto procedural determinista.
- Habitaciones conectadas.
- Paredes y aberturas para los corredores.
- Suelos y techos.
- Iluminación inicial.
- Punto de aparición de jugadores.
- Marcadores para monstruos.

Los modelos definitivos, laboratorios decorados, puertas funcionales,
objetos de misión, sonidos y zonas especiales se incorporarán en
las siguientes etapas.
