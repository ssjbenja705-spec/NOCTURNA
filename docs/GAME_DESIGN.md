# NOCTURNA: EL ÚLTIMO RECUERDO

## Identidad
Juego de terror cinematográfico cooperativo desarrollado para Roblox.

## Historia
El protagonista recibe una señal de su hermana desaparecida desde una instalación subterránea que oficialmente no existe.

## Capítulos
1. El Descenso.
2. Los que escuchan.
3. El Organismo.
4. Lo que no debía existir.
5. Ella.

## Monstruos
1. El Oyente: detecta sonidos.
2. El Imitador: utiliza voces para atraer jugadores.
3. El Quieto: permanece camuflado.
4. El Trepador: se desplaza por paredes y techos.
5. El Coloso: altera el escenario.

## Características
- Primera persona.
- Terror psicológico.
- Cooperativo.
- Misiones y diferentes finales.
- Iluminación cinematográfica.
- Sonido espacial.
- Controles para PC y móviles.
- Guardado de progreso.
- Administración y analítica.
- Optimización para celulares y tablets.
